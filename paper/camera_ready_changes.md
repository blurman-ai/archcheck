## Б. Расчёты, которые не требуют прогона

**Б1. Вывод детектируемости (R3).** Базовая частота p, истинное отношение r. В метке «агент» доля a = 0.2 ложных; в метке «человек» доля h = 0.3 скрытого ИИ.
Наблюдаемое отношение = [(1−a)·r + a] / [(1−h) + h·r] = (0.8·2 + 0.2) / (0.7 + 0.3·2) = 1.8 / 1.3 = **1.385**. Сходится с 1.38 в статье.

**Б2. Мощность знакового теста по табл. 2** (α = 0.05/7, мощность 80%, двусторонний). Последняя колонка — верхняя 95%-граница (Клоппер–Пирсон) доли реп, где агенты хуже, среди реп без ничьих:

| Категория | без ничьих | доля A>H | верхняя граница | минимальная обнаружимая доля A>H |
|---|---|---|---|---|
| complexity | 329 | 0.52 | 0.57 | 0.60 |
| new clone | 308 | 0.42 | 0.47 | 0.60 |
| SATD | 276 | 0.31 | 0.36 | 0.61 |
| test co-evo | 327 | 0.37 | 0.42 | 0.60 |
| cross-area | 164 | 0.37 | 0.43 | 0.64 |
| grown cycles | 38 | 0.21 | 0.35 | 0.78 |
| god headers | 81 | 0.35 | 0.44 | 0.70 |

Это закрывает вопрос R2 «какие истинные эффекты совместимы с табл. 2». Формулировка: «agents are worse in at most 57% of non-tied repositories for complexity (one-sided 95% bound); for grown cycles the design detects only an effect where agents are worse in ≥78% of non-tied repositories».

**Б3. Подписи вердиктов в табл. 2 (R1).** Для grown cycles, god headers, cross-area: «no deficit» → «insufficient events (n=38)» и т. д. по числу реп без ничьих.
